CRISPR-Ops

Don't just score the guide. Audit the assumption.

An autonomous audit of CRISPR off-target scores when the reference genome is not the allele a named population actually carries.

Team: Andrew Benjamin, Will, Mike

Research use only. Not a diagnosis. Personal genomes are refused.

10 October 2026

01 — Project overview

The reference genome is an assumption

Guide-RNA design tools score a spacer against one reference sequence and a mismatch count. Both can be the wrong object. A common variant can leave the mismatch count unchanged and still change the CFD score, because the mismatched base pair is now a different one. A variant can also land on a base the score ignores, such as the N of an NGG PAM, and the number does not move at all.

CRISPR-Ops takes a gene, a gnomAD population, and a panel of guide candidates. It audits how off-target scores behave under that population's common variants. The output is a method result with a trace of every tool call. It is not a clinical screen.

InputGene, population, 20 nt spacers. An optional note is checked against the refusal policy before any tool runs.
LoopPlan, act, verify, revise. The next tool depends on the last observation.
Thresholdτ = 0.2 CFD, registered before the run. Common variant means allele frequency ≥ 0.05.
ScopeSubstitutions only. GRCh38 chromosome 11 in the current demo. Bulges and indels are out of scope.

What a verdict means

A guide is FLAGGED when any non-on-target site has CFD ≥ 0.2, and CLEAR otherwise. A flip is a change between the reference haplotype and the population haplotype on the NGG wave. A score that stays below 0.2 is a statement about the scoring method, not a statement that a site is safe.

02 — Solution

An orchestrator with deterministic hands

The model is not a writer appended to a finished pipeline. When NVIDIA_API_KEY is set, Nemotron (nvidia/nvidia-nemotron-nano-9b-v2) chooses the next tool through the NeMo Agent Toolkit ReAct workflow. It may choose only from the legal set for that step. A choice outside the set is rejected and written into the trace. A sentence that adds a number the tools did not return is dropped.

Without the key, the model is not called. The registered policy chooses the branch, and the first line of the trace says so. A flipped verdict remains a consequence of τ = 0.2. If the model says to hold a PAM expansion after a flip, the policy keeps the expansion and records the override.

Decisions that make it an agent

DecisionWhat it does
TriageEvo 2 is spent only on sites with |ΔCFD| ≥ 0.05 or a score within 0.05 of 0.2, capped at four sites. The orchestrator may defer that spend.
DisagreementWhen the engine and the second checker disagree, the orchestrator names a hypothesis: strand, window start, or phasing. All three are tested. The trace says which one the tests support.
EscalationNAG and NGA are searched for one guide only, after its NGG verdict flips or a corrected checker still disagrees. Other guides stay on NGG.
RefusalA personal genome or a clinical question is rejected before enumeration. The refusal is logged.

03 — Uniqueness

The GPU is a decision, and the null is allowed

AgencyTriage, disagreement, escalation, and refusal are branches. The trace is the product, not a summary glued on at the end.
Two scoring axesCFD is a lookup. Evo 2 is the second axis, used where CFD moves or sits near τ. Likelihood is a prior, never ground truth.
Adaptive PAM scopeNAG and NGA are not brute-forced for every guide. The search widens only for the guide whose verdict moved.
Visible correctionA real strand bug in the second window builder is detected, hypothesized, re-run, and closed in the trace.

The scientific bar is the part that should not be softened for a demo. CFD is not treated as a validated oracle. A GUIDE-seq table is scored only if data/guideseq.tsv is present. If population-aware ranking does not beat the reference-only ranking, the result is the null. This build does not claim a correlation.

Absolute CFD values are reported against the registered threshold. On the chromosome 11 panel, the one common South Asian overlap does not move CFD. That is reported as method behavior: the substitution is the N of the PAM, and CFD multiplies mismatch weights and the last two PAM bases.

The demo does not fill in an allele frequency, a CFD split, or an experimental correlation that this run did not measure. The reference base at the overlapping site is not a minority allele.

Deterministic toolsenumerate_sites, fetch_af, score_cfd, crispr_me_check, resolve_disagreement, verify_citation. Pure functions. They do not choose the next step.
GPU layerevo2_score on the BioNeMo NIM. gpu_enumerate from cuda/enumerate.cu. Called when triage or escalation says the cheap pass is not enough.

Enumeration

The CPU binary in cpp/enumerate.cpp has two algorithms, PAM-skip and a full scan. Their hit lists are required to match. The CUDA kernel uses the same hit definition and the same TSV. On this machine there is no nvcc binary, so the expanded search falls back to the CPU enumerator and the trace says which device ran. A measured chromosome 11 NGG scan of one guide was about 1.3 seconds for PAM-skip and 1.5 seconds for the full scan, with equal hit lists.

Haplotype rule

The primary haplotype is the single highest-frequency SNV in the 23 bp window. gnomAD does not phase that window. A compound all-in-cis haplotype is recorded as a sensitivity when the checker builds one. It is not adopted as the verdict.

NeMo Agent Toolkit

workflows/crispr_ops.yml is the ReAct workflow: ten tools, max_tool_calls: 40, native tool calling, model nvidia/nvidia-nemotron-nano-9b-v2. nat validate accepts it. workflows/popoff_audit.yml runs the same audit with the policy choosing every branch, which is the path the local demo uses until a key is set.

05 — What this run measured

HBB, South Asian, chromosome 11

Three guides. HBB-HTY3 is a published exon-1 spacer against the reference allele. HBB-EX1-A and HBB-PROM are NGG sites read off GRCh38 at this locus. They are audit candidates, not therapeutic recommendations.

GuideReferencePopulationFlip
HBB-HTY3CLEARCLEARNo
HBB-EX1-AFLAGGEDFLAGGEDNo
HBB-PROMFLAGGEDFLAGGEDNo

Nineteen off-target sites were enumerated. One common South Asian SNV overlaps a window: chr11:13061395 C>T, allele frequency 0.25, on HBB-PROM at window chr11:13061375. CFD stays 0.0391 because the base is the N of the PAM. No guide flipped, so NAG and NGA were not searched. The second checker disagreed on minus-strand windows. The policy hypothesis was strand. The re-run agreed. The resolver moved from INVESTIGATE to ACCEPT.

Evo 2 was not scored, because the NVIDIA API key is unset and the endpoint was not called. The CUDA kernel was not timed.

Limitations, stated with the result

  • The loaded reference is GRCh38 chromosome 11, not the whole genome.
  • Substitutions only. The primary haplotype is one SNV, because gnomAD does not phase the window.
  • The cross-check is an in-repo second enumerator unless CRISPRME_BIN points at an external binary.
  • τ = 0.2 is a registered method cutoff, not a measured cutting rate.
  • Population-by-guide-by-site scoring across every gnomAD superpopulation was not built. This build does the enumeration kernel and the Evo 2 prior.

Research-use only. This is an audit of how off-target scores behave under population variation. It is not a clinical screen, not a diagnosis, and it does not accept personal genomes. Evo 2 likelihood is a sequence-context prior, not a cutting probability.
